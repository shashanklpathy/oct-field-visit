# Inside the Classroom: A field visit to Tamil Nadu, India (Stage 2 build)

A static website. No database, no accounts, nothing to install.

## What is in this folder
- `index.html`  The home page: introduction, the game, and the Insights Library banner.
- `library/`    The five Insights Library pages (Learners, Instructors, Programme, State partnership, Ideas we tested).
- `js/library.js`  All the library content: every card, in one file. Edit text here.
- `js/lib-render.js`  Builds the library pages: cards, filters, summaries.
- `js/content.js`  Every word the site shows, and all game content. Edit text here.
- `js/scenes.js`   The illustrations (drawn in code) and where the tappable hotspots sit.
- `js/shell.js`    The shared header, navigation and footer.
- `js/game.js`     The game engine: timer, scoring, clues, results.
- `css/styles.css` The look of the site.
- `assets/fonts/`  Fonts, stored here so the site makes no outside requests.

## Trying it on your computer
Unzip the folder and double-click `index.html`. It opens in your browser.

## What it contains
Both centre visits (Namakkal and Chennai) and the five Insights Library pages. Names, the state partner's name and programme figures are deliberately NOT in the files; they are added only after approval, because the repository is public.
